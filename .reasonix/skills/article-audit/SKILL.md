# article-audit

五平台文章安全审核。当用户提供文章（或在 pipeline 中被调用）时执行。

## 执行流程

1. 保存文章为 `outputs/{标题简称}_raw.md`（标题简称取前4字+方向名）
2. 运行审核：
   ```bash
   python scripts/audit_article.py outputs/{文件名}_raw.md
   ```
3. 根据结果处理：
   - **PASS（≥90分）** → 进入排版
   - **改（<90分）** → 输出问题清单，进入修复循环

## 审核检查项

审核依据：`五平台提示词工程/!!!!!!!!!!!!!!!审核打分规则汇总!!!!!!!!!!!!!!!.txt`

| 检查项 | 说明 |
|--------|------|
| 标题危险词 | CDA、报考、报名、培训、课程等 → REJECT |
| 标题视角 | 公司视角（值得考吗/一定要考）-20 |
| 标题评分 | 只减不加：培训-40 / 报名-50；其他合规判定不加分 |
| CDA全文总量 | ≥5且<10正常不扣分，≥10 -10，≥12 REJECT，3-4 -5，≤2 -15 |
| CDA位置 | 不能在第一段(-20) / 最后一段(-20) |
| CDA首次出现 | 第3-5段之间（第2段略早，前3段无则警告） |
| CDA话术多样性 | 相同CDA句子重复出现 -10 |
| 营销词 | 必须/一定/唯一/最好/强烈推荐/推荐/报名/课程/培训/购买/咨询，每词-5，同词>4次→REJECT |
| AI痕迹词 | 首先/其次/总而言之 + 一/二/三/四/五段落编号，每类-5 |
| 表格 | 禁止（排版不支持）-10 |
| 小圆点 | 禁止（排版不支持）-5 |
| 结构缺失 | 无能力建设→REJECT；缺1-2项-10，缺3+项-20 |
| 账号画像 | 只减不加：培训-50；其他合规判定不加分 |
| 尾缀 | 必须包含「扫码CDA认证小程序」 |
| CSDN | 标题禁CDA、前三段自然融入、无营销语气 |
